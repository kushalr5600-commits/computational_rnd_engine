## TASK 3 — Root Cause: The Missing Butterfly Stage

### The Bug

**File:** `vectors/gate_9b345_mlkem.py`, line 47

```python
def ntt_forward(f):
    f = list(f[:256])
    k_idx = 1
    length = 128
    while length >= 2:          # <-- BUG: should be "while length > 0"
        start = 0
        while start < 256:
            zeta = ZETAS[k_idx]
            k_idx += 1
            for j in range(start, start + length):
                t = (zeta * f[j + length]) % Q
                f[j + length] = (f[j] - t) % Q
                f[j] = (f[j] + t) % Q
            start += 2 * length
        length >>= 1
    return f
```

**Line 64 (INTT):** Symmetric bug: `while length <= 128` starting at `length = 2`
skips the innermost butterflies.

### Why It Fails

For N=256, the Cooley-Tukey NTT requires log2(256) = **8 butterfly stages**:
length = 128, 64, 32, 16, 8, 4, 2, **1**.

The `while length >= 2` condition executes stages for length = 128, 64, 32, 16, 8, 4, 2
(7 stages), then `length >>= 1` produces length=1, which fails `>= 2`, and the loop exits.

**Missing: the length=1 stage** (innermost butterflies, 128 groups of 2 elements each).

### Zeta Consumption Analysis

| Stage | Half-length | Groups | ZETAS consumed | Cumulative |
|-------|-----------|--------|----------------|------------|
| 1 | 128 | 1 | [1..1] | 1 |
| 2 | 64 | 2 | [2..3] | 3 |
| 3 | 32 | 4 | [4..7] | 7 |
| 4 | 16 | 8 | [8..15] | 15 |
| 5 | 8 | 16 | [16..31] | 31 |
| 6 | 4 | 32 | [32..63] | 63 |
| 7 | 2 | 64 | [64..127] | 127 |
| **8 (missing)** | **1** | **128** | **[128..255]** | **255** |

Total zetas consumed: 127 (buggy) vs 255 (correct). ZETAS array has only 128 entries
(0..127), so even fixing the loop bound would require expanding ZETAS to 256 entries.

### RTL Correctness

The RTL `ntt_core.sv` uses `stage_counter` from 0 to `LOG2_N-1 = 7` (line 180/223),
executing **all 8 stages**. Twiddle factors are computed as:
```
tw_idx = (pair % m) * (N >> (stage + 1))
```
This naturally covers all stages including the final length=1 butterflies.
